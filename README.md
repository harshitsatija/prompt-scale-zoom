# Prompt

An interactive logarithmic zoom through one 3D world: a woman types a question into a laptop in Bangalore. Zoom in through her brain, neurons, a synapse and a molecule. Zoom out through her room, building, city, India, Earth, the solar system, the galaxy and the cosmic web to the edge of the observable universe.

Open `index.html` through any static web server (modules and WebGL 2 are required). Scroll, drag, use the arrow keys, the slider or the zoom buttons.

Built with three.js. Data sources and licences for each level are listed in `assets/<level>/SOURCES.md` (PDB structures, NeuroMorpho, OpenStreetMap contributors (ODbL), NASA imagery, JPL elements, HYG star catalogue, galaxy surveys, Planck).
